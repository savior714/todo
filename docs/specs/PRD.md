# 📄 최종 PRD: FamilySync (가족 공유 육아/살림 트래커)

## 1. 제품 개요 (Product Overview)
- **목적**: 7세, 4세 아이를 둔 다중 양육자(부부, 조부모님) 환경에서 육아/집안일 진행 상태를 실시간 공유하고, 주 양육자(엄마)의 지침을 쉽게 전달하여 커뮤니케이션 비용과 중복 노동을 없앤다.
- **타겟 디바이스**: 모바일 웹 (PWA - 홈 화면에 아이콘 추가하여 앱처럼 사용)
- **핵심 정체성**: **"엄마의 머릿속에 있는 육아/살림 매뉴얼을 가족들에게 배포하고 실행을 돕는 시스템"**

## 2. 핵심 UX 원칙 (Core Principles)
1. **No Typing, Big Touch**: 조부모님을 위해 텍스트 입력은 최소화하고, 직관적이고 거대한 버튼 위주로 구성한다.
2. **Contextual Info (상황 맞춤형 정보)**: 정보를 찾게 하지 않는다. 특정 행동(예: 세탁)을 할 때 필요한 정보(예: 세제 위치)가 화면에 자동으로 나타나야 한다.
3. **Real-time (실시간)**: 새로고침 없이 모든 정보가 즉시 동기화되어 중복 사고(예: 투약 중복)를 막는다.

## 3. 유저 권한 및 인증 플로우
- **인증 방식**: Google Auth로 최초 로그인 후, **넷플릭스 스타일의 가족 프로필 선택 화면** 진입 (세션 무한 유지).
- **권한 분리**:
  - **[관리자 (엄마)]**: 숙제 설정, 가이드(사진/메모) 작성, 오늘의 지시사항(Pin) 작성 권한 보유.
  - **[실행자 (조부모님, 아빠)]**: 퀵 액션 버튼 클릭, 숙제 완료 체크, 타임라인 조회만 가능.

## 4. 핵심 기능 명세 (Core Features)

### F1. 메인 대시보드 (Main Dashboard)
- **📌 오늘의 지시사항 (Daily Pin)**: 화면 최상단에 노란색 포스트잇 형태로 고정 노출 (예: *"오늘 4세 콧물이 나니 하원 후 병원 들러주세요"*).
- **👕 상태 보드 (Status Board)**: `태권도복`, `유치원복` 등 특정 항목의 마지막 세탁일을 뱃지 형태로 자동 계산하여 노출 (2일 경과 시 붉은색 경고).
- **💬 실시간 타임라인**: 화면의 60%를 차지. 누가 언제 무엇을 했는지 실시간 피드로 제공. 다른 사람이 완료 시 **녹색 토스트 알림** 팝업(3초).

### F2. 원터치 퀵 액션 (Quick Actions)
- **💊 투약 (최우선 순위)**: [7세/4세] 선택 -> 완료 (타임라인 최상단 붉은색 강조).
  - *안전장치*: 2시간 내 중복 투약 시도 시 강력한 경고 팝업.
- **🎒 등/하원**: [7세/4세] -> 장소 선택(유치원/태권도장/피아노) -> 완료.
- **🦷 양치질**: [7세/4세] -> [아침☀️ / 저녁🌙] -> 완료.
- **🍚 식사**: [아침/점심/저녁/간식] -> 완료.
- **🧹 집안일**: [청소/세탁] -> 완료.
  - *안전장치*: 타임라인에서 **[실행 취소(Undo)]** 가능. 저위험 기록은 등록 후 24시간, 투약은 30분 이내(정책은 `lib/event-undo-policy.ts` SSOT).

### F3. 📚 숙제 트래커 (Homework Tracker)
- **동작**: 7세/4세 별로 오늘 해야 할 숙제 리스트 노출 (예: 구몬, 영어 흘려듣기).
- **관리**: 엄마가 설정 탭에서 숙제 항목을 추가/삭제/수정 가능 (매일 자정 체크박스 리셋).

### F4. 📖 우리집 가이드 & 상황별 힌트 (Family Wiki)
- **동작**: 엄마가 옷장 칸막이, 세제 위치, 약통 위치 등을 **사진 1장과 짧은 글**로 등록.
- **상황별 노출**: 할머니가 [세탁] 버튼을 누르면, 팝업창 하단에 자동으로 *"💡 Tip: 아기 세제는 세탁기 위 선반 오른쪽"* 가이드가 뜸.
- **가이드 탭**: 하단 네비게이션을 통해 언제든 전체 매뉴얼 열람 가능.

## 5. 기술 스택 및 데이터베이스 스키마
- **Frontend**: Next.js (App Router), React, TailwindCSS, PWA 설정
- **Backend / DB**: Turso (libSQL), Drizzle ORM, Auth.js (세션은 DB 어댑터)
- **Hosting**: Vercel

**[핵심 DB 테이블 구조]**
1. `profiles`: 가족 구성원 정보 (id, name, avatar_url, role)
2. `events`: 타임라인 기록 (id, profile_id, action_type, target, metadata-JSONB)
3. `daily_pins`: 오늘의 지시사항 (id, content, is_active)
4. `homework_types` & `homework_logs`: 숙제 마스터 및 일일 완료 기록
5. `care_guides`: 우리집 가이드 (id, category, title, image_url, linked_action)

## 6. 개발 로드맵 (Phased Execution Plan)

이 방대한 기능을 한 번에 만들면 지칩니다. 작동하는 결과물을 빠르게 확인하기 위해 4단계로 나누어 개발합니다.

### 🚩 Phase 1: 뼈대 구축 및 코어 타임라인 (Week 1)
- **목표**: 가족들이 넷플릭스처럼 로그인하고, 버튼을 눌러 타임라인에 기록을 남길 수 있다.
- **작업 내용**:
  - Next.js + Turso(Drizzle) 프로젝트 세팅
  - DB 테이블 생성 (`profiles`, `events`)
  - Google Auth 및 프로필 선택 UI 구현
  - 기본 퀵 액션 버튼(투약, 식사) 및 타임라인 UI(서버 데이터 + 갱신)

### 🚩 Phase 2: 육아 특화 기능 확장 (Week 2)
- **목표**: 7세/4세의 디테일한 일정과 상태를 추적한다.
- **작업 내용**:
  - 하원(장소 포함), 양치(아침/저녁) 액션 추가
  - 숙제 트래커 DB 및 UI 구현 (엄마 전용 설정 페이지 포함)
  - 상태 보드(태권도복/유치원복 세탁일 추적) 로직 구현

### 🚩 Phase 3: "엄마의 매뉴얼" 시스템 도입 (Week 3)
- **목표**: 조부모님이 질문 없이 스스로 정보를 찾고 실행할 수 있게 돕는다.
- **작업 내용**:
  - 가이드 사진 업로드(객체 스토리지·URL 저장 등) 연동
  - `care_guides` 테이블 구축 및[가이드 탭] UI 구현
  - **핵심**: 퀵 액션 버튼 클릭 시 관련 가이드(힌트)가 팝업에 자동 노출되는 로직 구현
  - `daily_pins` (오늘의 지시사항) 상단 고정 기능 추가

### 🚩 Phase 4: 폴리싱 및 배포 (Week 4)
- **목표**: 실제 사용 시 발생할 수 있는 사고를 막고 앱의 완성도를 높인다.
- **작업 내용**:
  - 투약 중복 방지 경고창 및 액션별 Undo(실행 취소) 정책 적용
  - 실시간 토스트 알림(Toast Notification) UI 추가
  - PWA(Progressive Web App) 세팅 (스마트폰 홈 화면에 앱 아이콘 추가 기능)
  - Vercel 최종 배포 및 가족 초대
