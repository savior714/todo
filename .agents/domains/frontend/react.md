# React & Frontend UI Rules

## MUST

- **PascalCase** 컴포넌트명·파일명
- **재사용 UI** 추출
- **반응형** 레이아웃 고려

## MUST NOT

- 소문자 JSX 컴포넌트명
- 단일 TSX에 과도하게 몰아넣은 거대 컴포넌트
